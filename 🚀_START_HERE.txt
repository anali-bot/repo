🎯 DÉMARRER EN 3 ÉTAPES:


  ┌─ 1️⃣  TESTER LOCALEMENT (RECOMMANDÉ) ─────────────────────────────┐
  │                                                                   │
  │  Ouvrez un terminal et tapez:                                   │
  │                                                                   │
  │    cd /home/aylon/Bureau                                         │
  │    python3 app.py                                                │
  │                                                                   │
  │  Puis allez à: http://localhost:5000                            │
  │                                                                   │
  │  Testez: inscription, connexion, associations, profils...       │
  │                                                                   │
  └─ ⏳ 2 minutes max ────────────────────────────────────────────────┘


  ┌─ 2️⃣  CRÉER UN COMPTE RENDER (GRATUIT) ───────────────────────────┐
  │                                                                   │
  │  1. Allez sur: https://render.com                               │
  │  2. Cliquez "Sign up" avec GitHub                               │
  │  3. Autorisez Render                                            │
  │                                                                   │
  └─ ⏳ 1 minute max ────────────────────────────────────────────────┘


  ┌─ 3️⃣  DÉPLOYER VOTRE SITE ─────────────────────────────────────────┐
  │                                                                   │
  │  1. Push votre code sur GitHub:                                 │
  │     git add .                                                    │
  │     git commit -m "🚀 WayMe - Production ready"                │
  │     git push origin main                                        │
  │                                                                   │
  │  2. Sur Render.com:                                             │
  │     - Cliquez "New +" → "Web Service"                           │
  │     - Sélectionnez votre repo wayme                             │
  │     - Build Command: pip install -r requirements.txt            │
  │     - Start Command: gunicorn -w 4 -b 0.0.0.0:$PORT app:app   │
  │     - Cliquez "Deploy"                                          │
  │                                                                   │
  │  3. ⏳ Attendez 3-5 minutes...                                  │
  │                                                                   │
  │  4. 🎉 Votre site est en ligne!                                │
  │     URL: https://wayme.onrender.com                            │
  │                                                                   │
  └─ ⏳ 10 minutes total ────────────────────────────────────────────┘

❓ QUESTIONS RAPIDES:


Q: Ça coûte combien?
A: ❌ C'est gratuit! Render et Railway offrent un tier gratuit.


Q: C'est difficile?
A: ❌ Non! Juste 4 clics: GitHub → Render → Repo → Deploy


Q: Je peux ajouter un domaine personalisé?
A: ✅ Oui! Freenom.com ou eu.org (gratuit)
   Puis configurer sur Render


Q: Mes données sont sauvegardées?
A: ✅ Oui, dans users.json
   💡 À considérer: migrer vers DB pour le long terme


Q: Puis-je ajouter plus de features après?
A: ✅ Bien sûr! Modifiez et faites git push
   Render redéploie automatiquement
