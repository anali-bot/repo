🚀 DÉPLOYER EN 30 SECONDES:

  1. Push sur GitHub:
     $ git add .
     $ git commit -m "🚀 WayMe - Production ready"
     $ git push origin main

  2. Allez sur Render.com:
     - Sign up avec GitHub
     - New Web Service
     - Sélectionnez votre repo
     - Deploy!

  3. Attendez 3-5 minutes

  4. 🎉 Votre site est en ligne!
     → https://wayme.onrender.com
